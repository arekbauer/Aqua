# Security Policy

## Privacy & Data Policy

Aqua is built as a 100% local-first application:

- **Zero Cloud Storage**: All hydration records, daily goals, and settings remain exclusively on your device.
- **Zero Telemetry or Tracking**: Aqua contains no analytics, advertising SDKs, or third-party tracking scripts.
- **Data Ownership**: Exported JSON backup files are created locally on your device under your complete control.

## Supported Versions

Only the latest stable version of Aqua receives active security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | Yes                |

## Reporting a Vulnerability

If you discover a security vulnerability or potential data handling risk in Aqua, please report it responsibly:

1. **Private Disclosure**: Avoid opening a public GitHub issue for sensitive security vulnerabilities.
2. **Contact**: Open an issue marked as a security report or contact the maintainer directly.
3. **Response Time**: Initial acknowledgment within 48 hours.
