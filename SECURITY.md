# Security Policy

## 🔒 Privacy & Data Policy

Aqua is built from the ground up as a **100% local-first** application:

- **Zero Cloud Storage**: All hydration records, daily goals, and settings remain exclusively on your device.
- **Zero Telemetry or Tracking**: Aqua does not contain analytics, advertisement SDKs, or third-party tracking scripts.
- **Data Export Ownership**: Exported JSON backup files are created locally on your device under your complete control.

## 🚨 Reporting a Vulnerability

If you discover a security vulnerability or potential data handling risk in Aqua, please report it responsibly:

1. **Private Disclosure**: Do not open a public GitHub issue for sensitive security vulnerabilities.
2. **Email**: Send details of the issue to the maintainer via [GitHub Issues](https://github.com/arekbauer/Aqua/issues) or directly via email.
3. **Response Time**: You will receive an initial response within 48 hours.

Thank you for keeping Aqua and its users safe!
